# Reference solutions (spoilers)

One write-up per challenge: how the evidence leads to the cause, the fix, and
the numbers measured on the machine this lab was built on. `patches/` holds
each fix as a diff against the untouched lab:

    patch -p1 --dry-run < solutions/patches/02-order-placement.patch

They are reference solutions, not the only ones. If your fix passes the test
and respects the rules, it is a solution; compare afterwards.
